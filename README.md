# GPU Learn

منهج إنجليزي كامل بالعربي لمدة 12 شهر، من المستوى A1 لحد B2.
A complete 12‑month English course for Arabic speakers, from CEFR A1 to B2.

**افتح الموقع / Open the site:** https://parmna432-eng.github.io/gpu-learn/

## شنو بيه / What's inside

- **48 أسبوع** على أربع مستويات CEFR (A1، A2، B1، B2)، كل مستوى 3 أشهر.
- **768 كلمة، 384 جملة، و48 قصة** بحوارات من 8 أسطر ويا شخصيات أصلية.
- **كل أسبوع:** درسين كلمات (22 لـ 24 تمرين لكل درس)، ودرس قواعد بشرح عربي، وقصة، ومحادثة.
- **جلسة يومية من 40 دقيقة لساعة:** مراجعة، درس جديد، تمرين استماع وكتابة، ومحادثة.
- **مراجعة بالتكرار المتباعد** (نظام صناديق لايتنر).
- **اختبار نهاية كل شهر،** وشهادة تشجيعية بعد كل مستوى.
- **تقرير تقدّم:** المهارات، ونقاط "شنو تگدر تسوي"، ونتائج الاختبارات.

## ملاحظات / Notes

- الموقع ملف واحد (`index.html`) وما يحتاج سيرفر.
- التقدّم ينحفظ بمتصفح المستخدم (localStorage) بس.
- **المحادثة الذكية وأصوات Claude** تشتغل بس لما ينفتح الموقع داخل Claude. على GitHub Pages المحادثة تطلع متوقفة، والنطق يستعمل صوت المتصفح.
- المحتوى مكتوب خصيصاً لهذا الموقع، ومبني على إطار CEFR ومبادئ تعليمية معروفة. الشهادات داخل التطبيق تشجيعية ومو رسمية.

The site is a single static `index.html`. Progress is stored in the browser. The AI conversation partner and Claude voices only work when the page is opened inside Claude; on GitHub Pages the chat is disabled and pronunciation uses the browser's built‑in speech.
